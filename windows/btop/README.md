# btop

System monitor.

## Role in the stack

- Primary system monitor.
- Shows CPU, memory, disks, and network.

## Installation

Preferred:

```powershell
scoop install btop
```

## Alternatives

### Task Manager

- Native Windows system monitor.
- Graphical and always available.

### Get-Process

- Native PowerShell process listing.
- No interactive UI.
