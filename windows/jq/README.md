# jq

Command-line JSON processor.

## Role in the stack

- Primary JSON tool.
- Parses, filters, and transforms JSON in the terminal.

## Installation

Preferred:

```powershell
scoop install jq
```

## Alternatives

### PowerShell JSON cmdlets

- `ConvertFrom-Json` and `ConvertTo-Json`.
- Slower and less expressive than jq.

### Python

- `json.tool` and Python scripts.
- Requires a Python runtime.
