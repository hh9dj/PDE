# Yazi

Terminal file manager.

## Role in the stack

- Primary file manager.
- Runs inside WezTerm.
- Provides fast keyboard-driven file navigation.

## Installation

Preferred:

```powershell
scoop install yazi
```

Check availability with:

```powershell
scoop search yazi
```

Some packages may require additional buckets.

## Alternatives

### Oil.nvim (fallback)

- File navigation inside Neovim.
- Edits the filesystem through a buffer.
- Use it when you want to stay inside the editor.

### Windows Explorer (fallback)

- Native graphical file manager.
- Use it when the terminal is not available.
