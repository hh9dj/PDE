# bat

## Dependencies

- `bat` 0.25+ (scoop). The theme `Catppuccin Latte` is built in.

## Setup

`setup_bat`: copies `config` to `~\.config\bat\config` (the profile sets `BAT_CONFIG_PATH`).

## Configured features

- Theme `Catppuccin Latte`.
- `cat` = `bat --paging=never`. The PowerShell alias `cat` (Get-Content) is removed.
