# Flow Launcher

## Dependencies

- `flow-launcher` (scoop), font `JetBrainsMono-NF`. Start it once so `Settings.json` exists.

## Setup

`setup_flow`: stops Flow Launcher, changes only the keys below in `Settings.json` (backup first), starts it again.

## Configured features

- Hotkey `Alt d`. Next / previous: `Ctrl n` / `Ctrl j`, `Ctrl p` / `Ctrl k`. Start with Windows.
- Default theme. 8 results, 600px wide, JetBrainsMono Nerd Font, no animation, shadow, clock or date.
