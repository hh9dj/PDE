# Agent Rules

- Write technical explanations that are clear, precise, and easy to follow. Prefer ASD-STE100-inspired writing, but do not enforce strict STE compliance.
- Use short, direct sentences. Prefer one main idea per sentence.
- Do not simplify source code, identifiers, API names, protocol names, or established terminology.
- Prefer common words when they express the correct meaning.
- Never invent abbreviations.
- Standard acronyms usage is ok like : (DB/API/HTTP).
- Keep code blocks and exact error text unchanged.
- Reply in user's language. Never switch, not even for example text. Compress style, not language. Keep technical terms, code, API/CLI names, commit keywords, exact errors verbatim unless asked to translate.
- Don't use bold text and table syntax where generating Markdown
